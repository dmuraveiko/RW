# Документация RealWallet

## Рабочая документация

[project/index.md](project/index.md) — русскоязычная документация для разработки, совместной интеграции и архитектурного ревью:

- границы задачи;
- архитектура и сценарии;
- NATS/Ed25519-контракты;
- модель PostgreSQL;
- план разработки и критерии приёмки;
- надёжность, безопасность и эксплуатация;
- тестирование, риски и реестр закрытых технических вопросов.

Именно этот раздел следует передавать другим разработчикам и техническому директору.

## Исходные документы

Файлы `rw_cab0.txt`, `rw_status.txt` и `rw_topup.txt` — первоначально предоставленные материалы. Их канонические побайтовые копии находятся в `../raw/` и не редактируются.
